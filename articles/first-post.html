독립 웹사이트를 직접 구축하기 시작했다

2026.09.07

오늘부터 특정 플랫폼에 종속되지 않는 독립 웹사이트를 직접 구축하기 시작했다.

GitHub에 사이트 파일을 저장하고 Cloudflare Pages를 통해 인터넷에 배포하는 구조를 사용했다.

첫 번째로 배운 것

웹사이트는 처음 생각했던 것보다 단순했다. HTML 파일을 만들고 인터넷 서버에 올리면 실제 웹페이지가 된다.

자동 배포

GitHub의 파일을 수정한 뒤 Commit하면 Cloudflare가 변경사항을 자동으로 감지해서 사이트를 다시 배포한다.

앞으로 할 일

사이트 구조를 조금씩 확장하고, 글 작성과 관리가 편한 형태로 발전시킬 예정이다.
